# MC Design Background
- **Stack**: Next.js, Tailwind CSS, GSAP (GreenSock) for high-performance animations.
- **Design Philosophy**: Apple-style minimalism, heavy use of whitespace, and neutral tones.
- **Performance**: Optimized for sub-1s load times using WebP assets.
- **Brand Colors**: Carbon (#0E0E0E) and Brass (#C9A961).
